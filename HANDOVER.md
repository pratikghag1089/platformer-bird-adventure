# HANDOVER.md

## 1. What Was Built
A minimalist 2D platformer game where players control a bird that must navigate through gaps in moving pipes by jumping and ducking. The game features a complete gameplay loop with menu, playing, and game-over states, score tracking, and responsive controls. All core mechanics including physics, collision detection, obstacle generation, and rendering were fully implemented and passed QA review.

## 2. Getting Started
**Prerequisites:** Python 3.x and Pygame library.

**Installation:**
```bash
pip install pygame
```

**Running the game:**
```bash
python main.py
```

**Controls:**
- SPACE or UP ARROW: Jump (double-jump available)
- DOWN ARROW: Duck (shrinks hitbox)
- R: Restart after game over
- ESC: Quit
